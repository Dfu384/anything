# Real multi-angle footage research

## Objectron — verified source, not cleared for game display

https://github.com/google-research-datasets/Objectron

The official README describes 15,000 real object-centric videos whose cameras move around bikes, books, bottles, cameras, cereal boxes, chairs, cups, laptops, and shoes. Inspected the repository's sample montage; it shows real photographs from oblique views with annotation overlays. Raw footage is separate from this annotated montage.

Candidate subjects: camera from the back, cup viewed from above, chair from behind, shoe viewed heel-first. These are selection ideas, not individually reviewed clips.

License: C-UDA-1.0 restricts data use to Computational Use. Do not ship footage in the public game without separately obtaining suitable display/distribution rights. Raw video downloads at storage.googleapis.com are currently blocked by the environment proxy (403).

## MVImgNet — verified source, terms and access unresolved

https://github.com/GAP-LAB-CUHK-SZ/MVImgNet

Official README describes 219,188 videos / 6.5 million extracted frames of real objects across 238 classes. Multi-view frames could provide an angle sequence. Download requires the provider's form and supplied access information. Data uses separate MVImgNet Terms of Use; the repository's noncommercial code license does not establish data display rights. No individual footage reviewed or downloaded.

## Production selection criteria

Choose footage with explicit web-game display rights. Start on an ambiguous but fair view; finish on a recognizable view. Avoid labels that reveal the answer. Inspect the whole clip, remove audio, and select a smooth 20-second sequence. Prefer at least 720p. Avoid faces and unnecessary background clues. Do not substitute a crop animation for an actual changing camera angle.
